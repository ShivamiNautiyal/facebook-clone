# Facebook Clone 🌐

A responsive Facebook Clone built to practice frontend development and recreate the basic layout and user interface of Facebook.

## ✨ Features

- Facebook-like homepage UI
- Navigation bar
- User profile section
- Posts and feed section
- Stories section
- Sidebar navigation
- Responsive design
- Mobile-friendly layout
- dark-light mode

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
